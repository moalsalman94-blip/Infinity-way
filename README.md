# Infinity Way — Business Solutions

الموقع الرسمي لـ **الطريق اللامحدود للخدمات الضريبية وحلول الأعمال**.

موقع ثابت (HTML/CSS/JS بدون أي build) — افتح `index.html` مباشرة أو انشره على GitHub Pages / Netlify.

- `index.html` — الصفحة
- `assets/css/style.css` — التصميم
- `assets/js/main.js` — المحتوى (عربي/إنجليزي) والحركات: جزيئات اللانهاية، المؤشر، البطاقات ثلاثية الأبعاد، النموذج المرسل عبر واتساب
